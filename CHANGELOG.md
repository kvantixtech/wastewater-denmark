# Changelog

`METHOD.md` was committed before the page and before any ranking was built. Changes to the method are listed here, with the reason, before they take effect.

## 2026-10-01: Fixed nitrogen concentrations

**Added:** the section "Fixed nitrogen concentrations" in `METHOD.md`.

**Why:** the page labels calculation levels 4–5 "based on measurement". While reading the page's table of the largest overflows, we saw that several level-4 outlets report nitrogen of exactly 12 mg/l. Level 4 concerns the water volume. The nitrogen figure can still be a fixed value times that volume. Without this addition, the page would suggest more measurement than there is.

**Order of work:** this was spotted after the 2024 data and the first results were published, so it is not a pre-registered question. It is a description, nothing is scored or ranked, and the definition is written here before it is added to `tools/build.py` and to the page.

**Results already published:** unchanged.
